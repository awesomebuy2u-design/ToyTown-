# ToyTown Android

Поточна версія: **1.0.18+28**. Flutter 3.35.7, Supabase.

Код застосунку тепер розміщено безпосередньо в `lib/`, тести — у `test/`, зображення — в `assets/pets/`. Архіви ZIP залишені як попередні версії; за наявності `pubspec.yaml` збірка використовує код з кореня репозиторію.

## Нове у 1.0.18

- Якщо інтернет обірвався під час надсилання іграшки з відкритої форми, кнопка «Повторити надсилання» використовує ту саму чернетку та фото. Повторна спроба не створює другого оголошення.

## Нове у 1.0.17

- Якщо запит на збереження PIN не завершився після підтвердження пошти, можна повторити збереження з тим самим підтвердженням, поки воно чинне. Підтримано код із листа та посилання Supabase для входу.

## Нове у 1.0.16

- Кабінет батьків захищено шестизначним PIN. Створення PIN підтверджується паролем акаунта, відновлення — листом. Після п’яти невдалих спроб діє блокування на 15 хвилин. Кабінет закривається після згортання застосунку або п’яти хвилин бездіяльності.
- Дитина може подати чернетку з фотографією прямо з полиці. Дорослий підтверджує її публікацію, керує повідомленнями та угодами, зберігає іграшки й може приховувати завершені угоди зі свого списку.
- На прогулянку містечком вирушає обраний улюбленець у своєму вбранні. Прогулянку можна повторювати.
- Кабінет показує ціни з підключених партнерських каталогів. Для іграшок із точною маркою й моделлю з’являється порівняння з новими товарами. Дійсні пропозиції є в наявності й оновлені протягом останніх 24 годин.

Для 1.0.16 потрібна міграція `20261127055516_toytown_1_0_16_guardian_marketplace.sql`. Після активації серверної перевірки для публікації, чату й угод потрібна версія 1.0.16 або новіша.

### Підключення партнерських каталогів

Перший кандидат — [«Будинок іграшок» в Admitad](https://www.admitad.com/ua/store/offers/budinok-igrashok-ua/). Додайте ToyTown як рекламний майданчик і підтвердьте, що офер приймає трафік із застосунку. Після схвалення сформуйте [повний XML/YML-експорт для України в гривнях](https://admitad.useresponse.com/knowledge-base/article/product-feed-what-it-is-and-how-to-export-it-for-your-website_4) без фільтра за датою зміни й без обмеження товарами зі знижкою. Використовуйте реферальні URL із погодженого фіда. Для «Антошки» доступ до фіда й умови можна уточнити через [відділ e-commerce](https://antoshka.ua/uk/partnership).

Перевірте зразок локально командою `python3 tools/sync_partner_feed.py --check-file catalog.xml`. Для автоматичної перевірки додайте секрет GitHub `TOYTOWN_PARTNER_FEEDS` із JSON-масивом об’єктів із полями `store_id`, `url` та опційним `offer_host`. У ручному запуску «Refresh registered partner catalogs» лишіть увімкненою опцію перевірки без запису. Імпортер очікує повний UTF-8 YML-каталог із часом формування та ознакою наявності.

Для активації зареєструйте активний магазин у `partner_stores` та вкажіть погоджений домен реферальних адрес у `offer_host`. Додайте серверний ключ Supabase до секрету `TOYTOWN_PARTNER_IMPORT_KEY`, увімкніть змінну `TOYTOWN_PARTNER_SYNC` зі значенням `enabled` і запустіть імпорт. Пропозиції без підтвердженої наявності або з фіда старшого за 24 години не показуються.

## Нове у 1.0.15

- Ігрова крамничка стала інтер’єром із 1–3 дерев’яними поличками. На них розміщуються підтверджені іграшки родини з фотографіями, а за відсутності фото — різними ілюстраціями. Гостьова вітрина явно позначена як приклад.
- Іграшки можна перетягувати між поличками або переставляти через меню. Чернетка зберігається окремо для акаунта й родини; кнопка «Зберегти полички» публікує оформлення для відвідувачів та інших пристроїв. Приховані й видалені оголошення виключаються на сервері.
- Прямі кнопки «Мої оголошення» й «Повідомлення» доступні з містечка та ігрової крамнички. Відкриття крамнички більше не перенаправляє до загального каталогу. Кнопка видалення оголошення помітна на його картці та внизу сторінки перегляду; власне оголошення розпізнається також при відкритті з каталогу.
- «Видалити чат у мене» прибирає всю переписку з особистого списку та історії користувача. Інший учасник і угоди зберігаються. Нове повідомлення повертає чат у список, але стару історію користувачу не повертає. Окреме видалення власних повідомлень залишається доступним.
- Пункт «Про ToyTown» у верхній панелі показує версію, щоб можна було перевірити встановлене оновлення.
- Нова міграція `supabase/migrations/20261123122152_family_shop_shelves_and_chat_clearing.sql` додає полички та персональне очищення чатів. SQL-перевірки виконуються лише в ізольованій базі із синтетичними родинами.

## Нове у 1.0.14

- У чаті дорослий може видалити власне надіслане повідомлення для обох родин. Біля нього є кнопка кошика та окреме підтвердження. Чужі повідомлення видалити не можна; право автора й участь у розмові перевіряють RPC та RLS.
- У «Моїй крамничці» можна видалити оголошення родини з будь-яким статусом. Воно зникає з крамнички, каталогу, мапи, пошуку й відкритого списку збережених іграшок. Посилання розмов та історія завершених/скасованих угод зберігаються: рядок архівується з `deleted_at`, а не видаляється фізично.
- Якщо є запропонована або погоджена домовленість, спочатку потрібно її скасувати чи завершити. Операція блокується на сервері; нова домовленість не може зарезервувати вже видалене оголошення.
- Повторне натискання під час запиту заблоковане; помилка не приховує запис і дозволяє повторити дію. Після видалення крамничка оновлюється, а старий запит завантаження чату не повертає вилучене повідомлення. Інша родина бачить оновлену розмову після її відкриття або натискання «Оновити».
- Виправлені перевірки прокручування мапи на вузьких екранах і оновлення списків у Flutter. Додані перевірки підтвердження/скасування, повторної спроби, власності записів та збереження історії.
- Перед запуском версії застосуйте `supabase/migrations/20261121170019_delete_own_content.sql`. Перевірка `test/sql/delete_own_content.sql` призначена лише для ізольованої тестової бази з двома синтетичними родинами; усі тестові зміни відкочуються.

## Нове у 1.0.13

- Мапа України показує справжні крамнички з підтвердженими оголошеннями. Демонстраційні позначки видалені; крамнички одного населеного пункту об’єднані в одну позначку.
- Пошук за містом, селом або назвою крамнички, вибір міста на мапі чи зі списку, перехід до крамнички та її іграшок. Посторінкове завантаження зберігає застосований пошук; лічильники стосуються завантажених крамничок.
- Офлайн-довідник GeoNames містить 32 463 центри населених пунктів України. Позначки не використовують GPS або домашні адреси; текст оголошень не передається геокодеру. Неоднозначні назви, крім назв обласних центрів, залишаються без позначки й доступні у загальному списку. Джерело, ліцензія та спосіб оновлення — `assets/places/README.md`.
- Помилки завантаження мають повторну спробу; збій фону мапи не блокує список. Нових змін схеми бази даних немає: використані чинні захищені RPC каталогу крамничок.

## Нове у 1.0.12

- Каталог справжніх крамничок родин доступний із містечка та каталогу іграшок після входу дорослого. Крамничка з’являється, коли є хоча б одне підтверджене оголошення.
- Пошук за містом або нейтральною публічною назвою, лічильник опублікованих іграшок, збережене оформлення вітрини та посторінкове завантаження.
- Усередині крамнички — лише її підтверджені оголошення з чинним переглядом, фотографіями, збереженням і чатом. Приховані й архівні оголошення виключаються на сервері.
- Публічна назва генерується окремо від назви родини. Публічна проєкція не містить імен батьків, дитячих профілів, даних улюбленця, балансу зірочок або приватних контактів.
- SQL-перевірка `test/sql/public_family_shops.sql` перевіряє дві родини, роль authenticated, статуси оголошень, пошук і сторінки та відкочує усі тестові зміни.

## Нове у 1.0.11

- Головна сторінка — інтерактивне містечко з ярмарком іграшок, власною крамничкою, будиночком улюбленця та ігровою галявиною. Кожна будівля відкриває відповідний розділ або мінігру.

- Переходи між вкладками відкривають початок сторінки. Нижня навігація та кабінет батьків доступні.
- Будівлі є розділами застосунку, а не оголошеннями чи вигаданими крамничками інших дітей. Реальні іграшки відкриваються через ярмарок. Змін бази даних для цієї версії немає.

## Нове у 1.0.10

- Мінігра «Знайди пару»: три пари карток, без таймера чи штрафів. За першу завершену гру нараховується щоденна зірочка завдання «Погратися з другом». Повторні ігри доступні без додаткової нагороди. Вихід із незавершеної гри не дає зірочок.
- Гра доступна гостям; для збереження щоденної нагороди потрібні акаунт, родина та інтернет. Завершення гри перевіряється клієнтом, щоденний ліміт нагороди — сервером. Зірочки залишаються косметичними ігровими балами.
- Безкоштовні набори «Класична», «Зоряна», «Хмаринки» змінюють вивіску, вітрину та підвіски. Вибір зберігається для родини та поєднується з кольором крамнички й придбаними прикрасами.

## Можливості

- Батьківський акаунт, родина, оголошення та модерація.
- Пошук іграшок, збережені оголошення, приватні чати та домовленості про обмін.
- Песик, котик і зайчик; ім’я, щоденний догляд, зірочки та дорослішання.
- Безкоштовний гардероб, кульки, квіти й навіс для крамнички.
- Збереження родинного прогресу та окремий локальний гостьовий прогрес.

## Перевірка та APK

```sh
flutter pub get
flutter test
flutter build apk --release --dart-define=SUPABASE_URL=YOUR_URL --dart-define=SUPABASE_ANON_KEY=YOUR_PUBLISHABLE_KEY
```

GitHub Actions запускає тести, створює прев’ю дизайну та підписану тестову APK. Артефакти `ToyTown-APK` і `ToyTown-Design-Previews` доступні на сторінці успішної збірки протягом 14 днів. Це тестова версія; наскрізні перевірки з двома акаунтами та встановлення на фізичний пристрій залишаються окремими перевірками.

Перевірки видалення та каталогу виконуються в окремій базі PostgreSQL у пам’яті з двома синтетичними родинами, без підключення до Supabase:

```sh
npm install --prefix /tmp/toytown-sql --no-audit --no-fund @electric-sql/pglite@0.5.17
node tools/check_content_deletion.mjs /tmp/toytown-sql/node_modules/@electric-sql/pglite/dist/index.js
```

Міграції 1.0.16 зберігаються в `supabase/migrations/`. Для чинної бази застосовуйте лише відсутні міграції.
